Fronteira React

Eixo independente

`feature → shared` pode ser arquiteturalmente permitido e ainda falhar se um Client Component importar um módulo `server-only`. Valide direção de camada e ambiente.

Checklist de review

  • O import entra pela API pública?
  • A origem pode conhecer a camada de destino?
  • Uma feature passou a conhecer outra?
  • O entry point mistura server-only e client-safe?
  • A regra automatizada cobre testes e aliases?
