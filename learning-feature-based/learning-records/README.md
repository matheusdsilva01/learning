# Learning records

Este diretório registra evidências de aprendizagem, não o conteúdo que foi apresentado.

Crie `NNNN-<descricao-curta>.md` somente quando houver uma destas evidências:

- uma classificação ou refatoração concluída;
- um teste, build ou regra arquitetural executada;
- uma justificativa que compare alternativas e trade-offs;
- uma concepção anterior corrigida com explicação própria.

Formato mínimo:

```md
# O que foi estabelecido

O que consigo fazer agora e por que isso muda o próximo passo.

## Evidência

Comando, arquivo, exercício ou explicação produzida.

## Limitação

O que ainda não foi demonstrado.
```

Material apenas lido ou uma resposta revelada pelo quiz não conta como evidência.
