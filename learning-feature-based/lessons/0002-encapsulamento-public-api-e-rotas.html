Módulo 2 • Arquitetura Avançada

Public API, Encapsulamento & Comunicação Inter-Feature

Como orquestrar módulos independentes sem criar dependências circulares e sem vazar abstrações.

⏱️ Tempo estimado: 7 minutos 🎯 Meta: Dominar Inversão de Controle com Slots, Thin Routes e Grafo Acíclico

1. O Grande Dilema: "Catalog precisa de Cart"

Em qualquer e-commerce real, a tela de catálogo exibe cartões de produto (features/catalog). Cada cartão possui um botão "Adicionar ao Carrinho" (features/cart).

Se o componente ProductCard importar diretamente AddToCartButton de @features/cart:

  • catalog torna-se rigidamente acoplado a cart.
  • Se cart precisar de validações de estoque vindas de catalog, cria-se uma dependência circular imediata.
  • Não é mais possível reutilizar ou testar o catálogo isoladamente (ex: em um Storybook ou microsserviço).

Padrão 1: Import Direto (O Antipadrão e a Dependência Circular)

Veja como o acoplamento ingênuo entre duas features gera dependência circular e quebras silenciosas em runtime:

1.1 O Código do Acoplamento

// Arquivo A: src/features/catalog/components/product-card.tsx import { AddToCartButton } from '@/features/cart'; // ❌ Catalog depende de Cart export function ProductCard({ product }: { product: Product }) { return ( <div className="product-card"> <h3>{product.name}</h3> <AddToCartButton productId={product.id} /> </div> ); }
// Arquivo B: src/features/cart/components/add-to-cart-button.tsx import { checkProductStock } from '@/features/catalog'; // ❌ Cart depende de volta de Catalog! export function AddToCartButton({ productId }: { productId: string }) { const isAvailable = checkProductStock(productId); return <button disabled={!isAvailable}>Adicionar ao Carrinho</button>; }
🚨 Saída do Bundler / Linter (Webpack, Vite ou ESLint): [CIRCULAR DEPENDENCY DETECTED] src/features/catalog/index.ts └─► components/product-card.tsx └─► @features/cart (index.ts) └─► components/add-to-cart-button.tsx └─► @features/catalog (index.ts) [CICLO FECHADO 💥] ⚠️ Consequência em Produção: 1. `checkProductStock` pode ser avaliado como `undefined` durante o carregamento inicial dos módulos. 2. Tree-shaking é destruído: quem usar apenas o Catálogo será obrigado a baixar 100% do bundle do Carrinho.
Padrão 2: Inversão de Controle com Slots (Slot Pattern)

O Catálogo expõe uma "abertura" (slot) e a página orquestradora injeta o botão do Carrinho:

// src/features/catalog/components/product-card.tsx (Agnóstico e Isolado) interface ProductCardProps { product: Product; + actionSlot?: React.ReactNode; // ✅ Slot aberto para qualquer ação externa } export function ProductCard({ product, actionSlot }: ProductCardProps) { return ( <article className="product-card"> <h3>{product.name}</h3> <span>R$ {(product.priceInCents / 100).toFixed(2)}</span> + <div className="card-actions">{actionSlot}</div> </article> ); }
// src/app/(shop)/catalog/page.tsx (Orquestrador / Thin Route) import { ProductGrid } from '@/features/catalog'; import { AddToCartButton } from '@/features/cart'; import { getProducts } from '@/features/catalog/api/get-products'; export default async function CatalogPage() { const products = await getProducts(); return ( <main> <h1>Catálogo Oficial</h1> <ProductGrid products={products} renderAction={(product) => ( + <AddToCartButton productId={product.id} /> // ✅ Injeção limpa de dependência )} /> </main> ); }

Padrão 4: Barramento de Eventos Desacoplado (Typed Event Bus)

Comunicação assíncrona entre fluxos transacionais (ex: Checkout finalizado notificando Toast e limpando Carrinho):

// src/shared/lib/event-bus.ts (Definição Tipada Global) import mitt from 'mitt'; import type { Product } from '@/entities/product'; export type AppEvents = { 'order:placed': { orderId: string; items: Array<{ product: Product; quantity: number }>; totalInCents: number; }; 'cart:item-added': { productId: string; quantity: number }; 'auth:session-expired': void; }; export const eventBus = mitt<AppEvents>();
// 1. Emissor: src/features/checkout/api/use-place-order.ts import { eventBus } from '@/shared/lib/event-bus'; export function usePlaceOrder() { return async function placeOrder(orderPayload: OrderDTO) { const response = await api.post('/orders', orderPayload); // 📢 Emite evento de negócio sem saber quem está ouvindo eventBus.emit('order:placed', { orderId: response.data.id, items: orderPayload.items, totalInCents: response.data.totalInCents }); return response.data; }; }
// 2. Ouvinte A: src/features/notifications/hooks/use-order-notifications.ts import { useEffect } from 'react'; import { eventBus } from '@/shared/lib/event-bus'; import { toast } from '@/shared/ui/toast'; export function useOrderNotifications() { useEffect(() => { const handleOrderPlaced = ({ orderId, totalInCents }: { orderId: string; totalInCents: number }) => { toast.success(`Pedido #${orderId} de R$ ${(totalInCents / 100).toFixed(2)} confirmado!`); }; eventBus.on('order:placed', handleOrderPlaced); return () => eventBus.off('order:placed', handleOrderPlaced); }, []); }
// 3. Ouvinte B: src/features/cart/hooks/use-cart-cleanup-listener.ts import { useEffect } from 'react'; import { eventBus } from '@/shared/lib/event-bus'; import { useCartStore } from '../stores/cart-store'; export function useCartCleanupListener() { const clearCart = useCartStore((state) => state.clearCart); useEffect(() => { // 🧹 Limpa o carrinho automaticamente quando um pedido for realizado eventBus.on('order:placed', clearCart); return () => eventBus.off('order:placed', clearCart); }, [clearCart]); }

4. A Anatomia de uma Public API Blindada

No arquivo src/features/cart/index.ts, devemos seguir três regras fundamentais:

1. Exportar apenas componentes de contêiner ou gatilhos

Exporte CartDrawer, AddToCartButton. Nunca exporte subcomponentes como CartItemSummaryRow.

2. Exportar seletores e contratos de leitura de estado

Exporte hooks como useCartSummary() ou useCartItemCount() para permitir que a navbar ou o checkout leiam dados consolidados.

3. Jamais exportar queries internas ou implementações mutáveis

Não exporte mutações brutas como useAddToCartMutation diretamente para fora da feature. Encapsule o comportamento em componentes ou hooks de alto nível.
