A API pública reduz a superfície de mudança; as ferramentas impedem que consumidores a contornem.

O que um índice faz — e não faz

`index.ts` oferece um endereço estável e documenta o contrato. Ele não torna outros arquivos privados no TypeScript. Sem package exports ou lint, qualquer consumidor ainda pode fazer import profundo.

// src/features/catalog/index.ts
export { ProductCard } from './components/product-card'
export type { ProductCardProps } from './components/product-card'

// src/features/catalog/index.server.ts
import 'server-only'
export { listProducts } from './api/list-products'

// Evite como política padrão:
// export * from './components'
// export * from './api'

Por que separar servidor

No App Router, `'use client'` define uma fronteira no grafo de módulos. Uma barrel que mistura UI cliente com acesso a banco ou segredos pode causar erro de build ou environment poisoning. `index.server.ts` torna o ambiente parte do contrato.

Comando de alto nívelCliente HTTP e detalhes de cache

Barrel e tree-shaking

Barrels podem afetar análise e bundles conforme ferramentas, side effects e grafo client/server. Não afirme que sempre ajudam ou sempre prejudicam; meça e mantenha exports explícitos.
