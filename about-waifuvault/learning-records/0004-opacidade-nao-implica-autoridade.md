# Opacidade não implica autoridade

O usuário distinguiu uma referência opaca de uma capacidade: conhecer um identificador opaco não concede necessariamente acesso, enquanto uma URL se torna capacidade de leitura quando sua posse basta para obter o arquivo sem outra autenticação. Também reconheceu que separar `publicToken` de `albumToken` permite revogar a leitura pública sem trocar a credencial privada de gerenciamento.

## Evidence

Após comparar os dois cenários, classificou corretamente uma URL que ainda exige login como “referência opaca” e uma URL cuja posse basta para baixar o arquivo como “capacidade de leitura”.
