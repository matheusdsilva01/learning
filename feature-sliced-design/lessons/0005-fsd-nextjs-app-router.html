Next.js App Router com FSD (Roteamento Fino)

🎯 Objetivo da Lição: Aprender a organizar projetos Next.js App Router mantendo a pasta app/ apenas como um roteador "fino" e transferindo a composição da aplicação para src/pages/ no FSD.

1. O Conceito de Thin Router (Roteador Fino)

Em vez de colocar lógica de negócios, chamadas de dados ou componentes diretamente no arquivo page.tsx da pasta app/, mantemos o page.tsx com pouquíssimas linhas de código.

2. Comparação de Código no Next.js App Router

❌ Sem FSD (page.tsx virando Monólito)

// app/movies/[id]/page.tsx
import { useState } from 'react';
import { useQuery } from '@tanstack/react-query';
import { Header } from '@/components/Header';
import { RatingStars } from '@/components/RatingStars';

export default function MoviePage({ params }) {
  // 50 linhas de hooks, chamadas de dados e formulários misturados aqui...
  return <div>...</div>;
}

✅ Com FSD (page.tsx como Rota Fina)

// app/movies/[id]/page.tsx
import { MovieDetailPage } from '@/pages/movie-detail';

export default function Page({ params }: { params: { id: string } }) {
  return <MovieDetailPage movieId={Number(params.id)} />;
}

3. Onde fica a camada de Páginas no FSD?

Toda a composição da tela vive dentro de src/pages/movie-detail: 

// src/pages/movie-detail/ui/MovieDetailPage.tsx
'use client';

import { Header } from '@/widgets/header';
import { MovieHero } from '@/widgets/movie-hero';
import { MovieReviewsList } from '@/widgets/movie-reviews';
import { RateMovieButton } from '@/features/rate-movie';

export function MovieDetailPage({ movieId }: { movieId: number }) {
  return (
    <main>
      <Header />
      <MovieHero movieId={movieId} action={<RateMovieButton movieId={movieId} />} />
      <MovieReviewsList movieId={movieId} />
    </main>
  );
}
