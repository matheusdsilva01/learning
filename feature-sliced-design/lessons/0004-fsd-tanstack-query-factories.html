TanStack Query & Query Key Factories no FSD

🎯 Objetivo da Lição: Estruturar buscas de dados (Queries) e mutações (Mutations) no FSD usando Query Key Factories para eliminar magic strings e padronizar a invalidação de cache entre fatias.

1. O Padrão Query Key Factory

Em vez de passar arrays soltos como ['movies', filters] espalhados pelo código, criamos um objeto centralizado dentro do model/ da entidade: 

// src/entities/movie/model/movieQueries.ts
import { MovieFilters } from './types';
import { fetchMovies, fetchMovieById } from '../api/movieApi';

export const movieQueries = {
  all: () => ['movies'] as const,
  lists: () => [...movieQueries.all(), 'list'] as const,
  list: (filters: MovieFilters) => [...movieQueries.lists(), filters] as const,
  details: () => [...movieQueries.all(), 'detail'] as const,
  detail: (id: number) => [...movieQueries.details(), id] as const,
};

2. Custom Hook na Entidade (entities/movie)

O hook da entidade consome a fábrica de chaves e a função da API: 

// src/entities/movie/model/useMoviesQuery.ts
import { useQuery } from '@tanstack/react-query';
import { movieQueries } from './movieQueries';
import { MovieFilters } from './types';

export function useMoviesQuery(filters: MovieFilters) {
  return useQuery({
    queryKey: movieQueries.list(filters),
    queryFn: () => fetchMovies(filters),
    staleTime: 1000 * 60 * 5, // 5 minutos de cache fresco
  });
}

3. Mutações e Invalidação de Cache na Feature (features/rate-movie)

Quando o usuário avalia um filme, a mutação na camada features/ precisa atualizar a UI invalidando a query do filme: 

// src/features/rate-movie/model/useRateMovieMutation.ts
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { movieQueries } from '@/entities/movie';
import { rateMovieApi } from '../api/rateMovieApi';

export function useRateMovieMutation(movieId: number) {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: (rating: number) => rateMovieApi(movieId, rating),
    onSuccess: () => {
      // Invalida especificamente o cache deste filme
      queryClient.invalidateQueries({ queryKey: movieQueries.detail(movieId) });
      // Ou invalida todas as listas de filmes se necessário
      queryClient.invalidateQueries({ queryKey: movieQueries.lists() });
    },
  });
}
