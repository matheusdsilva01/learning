Lição 0006 • Módulo 3: Framework Integration

Layouts, error.tsx, loading.tsx e API Routes no FSD

🎯 Objetivo da Lição: Entender exatamente onde posicionar Layouts, Error Boundaries (error.tsx), Skeletons (loading.tsx) e API Routes (route.ts) mantendo a pasta app/ do Next.js limpa.

1. Onde Fica Cada Arquivo Especial do App Router?

🏛️ Layouts (layout.tsx)

Root Layouts usam src/app/providers. Layouts com Sidebar/Header usam Widgets de src/widgets/dashboard-layout.

⚠️ Error Boundaries & Loading Skeletons

Componentes reutilizáveis ficam em src/shared/ui. Tratamentos específicos de páginas re-exportam de src/pages/{page-name}.

🔌 API Routes (route.ts)

Delegam a lógica de backend/BFF para funções puras dentro de src/entities/{domain}/api/server.ts ou src/shared/api.

2. Exemplo Prático de Código

// app/(dashboard)/movies/[id]/error.tsx
'use client';

// O arquivo de erro do Next.js apenas re-exporta a UI da página FSD!
export { MovieErrorState as default } from '@/pages/movie-detail';
