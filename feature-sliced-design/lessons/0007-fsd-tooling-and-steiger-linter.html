Tooling e Linting Automático (Steiger & ESLint) no FSD

🎯 Objetivo da Lição: Aprender a configurar o Steiger e o ESLint no seu projeto Next.js/React para travar automaticamente importações ilegais e proteger a arquitetura FSD em CI/CD.

1. O que é o Steiger?

O Steiger é o linter oficial mantido pela equipe do FSD. Ele inspeciona a estrutura das suas fatias, verifica se a API Pública (index.ts) está presente e impede que camadas inferiores importem de camadas superiores.

2. Como Instalar e Rodar o Steiger

Comando no Terminal

# Rodar diretamente via npx na pasta de código fonte:
npx steiger ./src

Configuração no package.json

{
  "scripts": {
    "lint:arch": "steiger ./src",
    "lint": "next lint && npm run lint:arch"
  }
}

3. Regras Validadas Automaticamente pelo Steiger

  • insignificant-slice-nesting: Impede aninhamento desnecessário e profundo de fatias.
  • public-api-imports: Garante que imports passem pela Public API (index.ts).
  • layer-imports: Bloqueia importações que violam a hierarquia (ex: shared importando de entities).
