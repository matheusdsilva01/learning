Feature-Sliced Design: Camadas, Segmentos e Regras

1. Resumo das 7 Camadas (Layers)

Camada Propósito Pode Importar De Exemplo de Conteúdo
app Inicialização, providers, estilos globais, rotas finas do Next.js Todas abaixo app/providers.tsx, app/(dashboard)/page.tsx
processes (Opcional/Legacy) Fluxos complexos entre múltiplas páginas pages, widgets, features, entities, shared checkout-flow
pages Composição de telas completas para as rotas widgets, features, entities, shared src/pages/profile/ui/ProfilePage.tsx
widgets Blocos de UI autônomos e compostos features, entities, shared Header, Sidebar, ProductGrid
features Ações de usuário com valor de negócio (formulários, botões interativos) entities, shared add-to-cart, login-by-email
entities Modelos de domínio de negócio (substantivos) shared user, product, order
shared Código independente de domínio (UI Kit, cliente HTTP, helpers) Nenhuma (Apenas libs externas) shared/ui/button, shared/api/fetcher

2. Os 5 Segmentos Padrão (Segments)

  • ui/: Componentes de interface visual (JSX/TSX).
  • model/: Estado, custom hooks, TanStack Query keys/queries/mutations, schemas Zod, types TypeScript.
  • api/: Requisições de rede puras (fetchers/Axios).
  • lib/: Funções utilitárias e helpers específicos daquela fatia.
  • config/: Constantes e configurações locais da fatia.

3. Regra Fundamental da Public API (Encapsulamento)

// ❌ ERRADO (Importação profunda ilegal):
import { UserAvatar } from "@/entities/user/ui/UserAvatar";

// ✅ CORRETO (Importação pela Public API index.ts):
import { UserAvatar } from "@/entities/user";
